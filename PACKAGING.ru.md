# Локальная проверка и упаковка для браузеров

Эти необязательные локальные команды ничего не публикуют, не настраивают CI/CD и не заменяют ручное тестирование в браузере. В рамках текущей подготовки репозитория сборка пакетов не выполняется.

## Предварительные требования

Используйте актуальную поддерживаемую LTS-версию Node.js. Скрипты используют только встроенные модули Node.js, поэтому установка зависимостей через пакетный менеджер не требуется. Для обычной разработки загрузите исходный каталог как распакованное расширение через `chrome://extensions`; см. [README.ru.md](README.ru.md).

## Команды

Выполняйте из корневого каталога репозитория.

```text
node tests/manifest-contract.test.mjs
node tests/release-certification.test.mjs
```

Эти детерминированные проверки валидируют manifest, проекции для целевых браузеров, правила состава пакета и контракт локальных release-evidence. Это не подтверждение совместимости с браузерами и не сертификация безопасности.

```text
node scripts/build-extension.mjs chrome
node scripts/build-extension.mjs edge
node scripts/build-extension.mjs firefox
node scripts/certify-local-release.mjs
```

Сборщик создаёт одноразовые локальные каталоги в `dist/<target>/`; и `dist/`, и генерируемый каталог evidence `release/` игнорируются Git. Команда evidence заново формирует локальные pre-certification записи в `release/readiness/<version_name>/`. Сгенерированный каталог или успешная проверка Node.js не являются кандидатом на релиз: вручную проверьте каждый целевой браузер, просмотрите разрешения и состав пакета, устраните документированные release-блокеры. Проект распространяется по лицензии MPL-2.0 (см. `LICENSE`); процесса выпуска в публичные магазины пока нет.
